# Personal Expense Tracker Monorepo

This repository contains the expense tracker applications organized as a monorepo. The React frontend under `client/`, the Express backend under `express/` and a Spring Boot backend under `springboot/`.

## Features

- Log daily expenses with details such as amount, date, and category.
- Categorize expenses to gain a clear overview.
- View detailed expense reports and charts.
- Secure login and registration system.
- Custom categories for expenses and incomes.

## Repository Layout

- `client/` React frontend
- `express/` Express API and Node.js backend
- `springboot/` Spring Boot API implementation
